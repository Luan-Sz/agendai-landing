Onde ver as métricas?

O GitHub Pages não executa Python nem SQLite. Por isso, o painel administrativo antigo não funciona aqui.

Cliques nos planos: consulte os eventos plano_escolhido, com parâmetro plano, no seu Google Analytics 4. Eles só serão enviados se o GA4 estiver configurado e o visitante permitir a medição.

Lista de espera: consulte as inscrições no painel do Formspree, após configurar o endpoint em config.js.

Nunca coloque senha administrativa, token secreto ou credenciais dentro dos arquivos do GitHub Pages. O conteúdo do repositório e os scripts do navegador são públicos.
